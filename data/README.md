Data 

This project uses the EEG Motor Movement/Imagery Dataset provided by PhysioNet.

Dataset: EEG Motor Movement/Imagery Dataset, version 1.0.0

Source: https://physionet.org/content/eegmmidb/1.0.0/

The dataset contains 64-channel EEG recordings sampled at 160 Hz.

For this project, we use the motor imagery runs corresponding to left- and right-hand fist imagery:

Run 4 Run 8 Run 12 

Raw EEG files are intentionally not included in this GitHub repository. Please download the required files directly from PhysioNet.

The raw files should be placed in:

data/raw/

Example:

data/raw/S001R04.edf
